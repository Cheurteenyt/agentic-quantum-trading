# Archived One-Off Scripts

This folder stores one-off maintenance scripts that should not be treated as
runtime code.

Rules:

- Do not import from here in backend/frontend runtime code.
- Keep scripts only when they explain past project operations.
- Prefer documenting the reason for archival instead of deleting immediately.
- If a script becomes useful again, move it into a proper active package or
  `scripts/` with tests/usage notes.
