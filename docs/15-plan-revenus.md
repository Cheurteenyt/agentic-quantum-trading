# La question à laquelle ce doc répond

Comment ce projet — et les compétences qu'il démontre — génèrent du revenu
réel, et avec quel horizon ? Réponse sans mensonge, en trois couloirs.

## Couloir VITE (semaines) — vendre la compétence, pas le projet

La vérité inconfortable : le moyen le plus rapide d'avoir de l'argent avec ce
qu'on maîtrise, c'est de le vendre en mission. Ce projet EST le portfolio :

- data engineering (pipeline klines, warehouse SQLite, séries temporelles),
- automation fiable (systemd user timers, scraping headless anti-détection,
  anti-throttle, tests),
- domaine crypto (perps, funding, onchain, mécanique Aster).

**Actions réservées à l'utilisateur** : repo GitHub public du registre
(le code propre le justifie), profil Malt/Upwork avec le registre en
vitrine, cibler les missions scrapers/dashboards/bots. Horizon : premier
revenu en 2-6 semaines si le portfolio est visible.

## Couloir MOYEN (1-3 mois) — des outils qui améliorent SON trading

- **Scanner de funding** (livré le 21/09) : les extrêmes annualisés sont
  directement exploitables par le trading manuel de l'utilisateur.
- **Le Registre** : 2-4 semaines d'accumulation de verdicts → premier track
  record public → ALORS seulement une offre (« les calls des gourous,
  vérifiés chaque nuit »). Le canal push (Telegram) est déjà branché mais
  n'est qu'un tuyau : rien à vendre avant des preuves.
- **Affiliations** (Aster, exchanges réellement utilisés) : elles convertissent
  avec de l'audience ou du volume — pas avant.

## Couloir LONG (3-12 mois) — l'edge et l'audience

- Edge live : la campagne tourne chaque nuit ; un candidat doit survivre
  30 jours de données inédites. Pas de live avant.
- Audience : build in public (drafts prêts chaque nuit dans reports/).

## La règle qui protège

Aucun de ces couloirs ne nécessite de mentir — pas de « signaux premium »
avant track record, pas de farming de wash-volume contre les ToS. C'est
l'avantage compétitif durable du projet : il refuse de se vendre en tant
que mensonge.
