# File d’hypothèses (pré-code)

Une hypothèse = un fichier `YYYY-MM-DD-slug.md`.

Template minimal :

```markdown
# titre

- domain: ASTER|FOMO|OPENMARKET|X
- horizon: H-1Y|H-MULTI|H-LIVE|H-MICRO
- mécanisme:
- prédiction:
- critère de mort:
- primitives parents: (ou “nouvelle primitive”)
- why_not_textbook:
- statut: DRAFT|IN_STUDY|DONE
```

Pas de code ici. Le code vit dans `scripts/studies/`.
